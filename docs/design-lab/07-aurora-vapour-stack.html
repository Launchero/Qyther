07 · Vapour Stack — mesh and glass, and where it stops being safe

Provenance — a trend, not a system. No spec owns it: the technique is MDN’s backdrop-filter reference, Apple’s Materials guidelines (blur + tint + inner highlight, iOS HIG), and Raycast’s marketing surfaces. There is no token file to vendor, no licence to comply with — and no authority to say when it is finished. That is what “adopting a trend” actually means.

The trap, stated plainly — 13px label #ffffff on #0ea5b7 measures 2.96:1: filled chromatic buttons cannot carry 13px white labels. This file uses oklch(0.30 0.09 230) fills with #eef1ff text instead 11:1-safe label, and every glass label sits on a plate the blobs cannot reach.

Type plan — a wide neutral grotesque with a display cut: Inter Display + Inter (SIL OFL 1.1 — vendorable), or General Sans (Fontshare — free for commercial use including webfonts, but not OFL, so verify the current licence text before vendoring). This mock references the family names only; nothing is loaded, offline it falls back to Segoe UI Variable. Scale 13 / 14 / 16 / 24 / 40 / 56 px, weight 500 dominant, letter-spacing: -0.01em. Mono only for tokens and costs.

Geometry — radius large and consistent: 14 / 20 / 28 px. This is the one direction where the app’s 8 px radius ceiling must rise: the single tokens/radius.css base moves every corner, including the pristine components/ui/ primitives. Borders are light-on-dark inner rings (inset 0 0 0 1px oklch(1 0 0 / .18)), not opaque lines. Elevation is blur-depth tiers — 12 px popover, 24 px modal, 40 px scrim — plus a 2 % white top-edge highlight; drop shadow only carries the mass, never the separation.

Motion — 260–420 ms on cubic-bezier(0.16, 1, 0.3, 1). The signature: the mesh blobs drift on a 46 s loop so the surface moves while the content stays dead still. Under prefers-reduced-motion the drift stops, the blur is dropped and the plates fall back to their opaque-correct values — that media query is in this file’s stylesheet, implemented, not described.

Damage report — translucency is an uncontrolled background: a row at 15 % alpha over a bright desktop icon can fall from 7:1 to under 3:1 with no CSS-visible change, and this app’s window is transparent: true and always-on-top, so the user’s actual desktop is behind it. Blur kills the 1 px hairlines that separate file rows — the row rhythm this palette is built on. Each blurred surface costs a compositor layer. And the window height is tweened by the main process via setBounds, so a plate that re-blurs mid-tween is a repaint cost the palette cannot pay. Recommendation: glass for the overlay / tooltip / toast scrim only; the result list is rendered on an opaque plate in every surface below — that is the safe subset, demonstrated, not asserted.

  • Move 1 — tokens/radius.cssRaise the base radius from 8 px to the 14/20/28 scale. One file; every corner in the app follows, pristine ui/ primitives included — which is exactly why it needs a full visual pass afterwards, not a diff review.
  • Move 2 — tokens/shadow.cssReplace the tinted drop-shadow scale with the blur-depth tiers (12/24/40 px) and the 2 % white top-edge highlight folded into each elevation token.
  • Move 3 — semantic/theme.cssNew translucent surface roles (--glass-plate, --glass-tint, --glass-ring) declared in both the :root and .dark halves, with the opaque fallback plate alongside so an @supports failure degrades by value, not by cascade.

Cost: colour, radius and shadow are token-only — the blocks above diff directly against semantic/theme.css. The plate wrappers and the @supports fallback are markup, and their host is src/renderer/components/CommandPalette.tsx. Motion tokens fold into tokens/motion.css as usual; the drift loop is a new shorthand and needs its reduced-motion mirror in globals.css.

Biggest risk: the contrast-of-the-background problem above. Every ratio quoted in this file (13.24:1 primary text on the violet field, 7.00:1 secondary, 16.50:1 ink on light paper) is measured against the token, not against what a translucent plate will actually sit on when the user’s wallpaper is a bright icon — and no automated gate can see that.
