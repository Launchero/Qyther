29 · Composed Stack — the synthesis the lab's own evidence points at

What this file is — not a thirtieth research direction. It is the stack that a critical read of the other 38 produces: 28's seed → derivative → alias tiering, 10's named layer ladder and the only density axis in this folder bound to data-window-mode, 17's numeric contract, 18's shape-plus-word status law extended to six states, 27's named elevation roles, and 05's per-role -shade / -foreground pairing.

What it adds — surface 0. The app's default surface is MODE_CONFIGS.compact.height = 72px, and --container-header-height is contractually equal to it, so the compact card is one header tall. Every other mock authors --header-h between 40px and 80px and renders only the expanded card; 13 of the 28 directions therefore cannot physically render the app's default state. Here it is rendered at 72px, beside an icon-only dock and a condensed/expanded density pair, all off the same aliases.

Geometry (retuned 2026-10-16 against primary sources) — width 800 → 680px. Every launcher with a shipped dimension is narrower than that: VS Code's Quick Open is 600px and PowerToys Run is 640px in shipped CSS/XAML, Raycast is commonly reported near 750px, and no primary source supports anything wider as a default. 680px sits inside the 640–760 convergence band and still beats VS Code on width, which matters for this app's long repo-relative paths. The only principled ceiling anyone publishes is readability (~70ch, Baymard; ≤80ch per WCAG 1.4.8) — no vendor publishes a launcher max. Control floor 32 → 40px: 32px clears WCAG 2.2 SC 2.5.8 AA (24×24 plus the 24px-circle spacing rule) but sits under Microsoft's own 7.5mm/40px targeting guideline, which is the wrong floor for a Windows app. 40px is also Carbon's md button/row. Row ladder unchanged at 32/40/48 — already Carbon's sm/md/lg verbatim. Spacing moved to rem on Carbon v11's published $spacing-01…13 (2/4/8/12/16/24/32/40/48/64/80/96/160), because rem is the majority output across Primer, Carbon, Atlassian, Tailwind and USWDS and a px rhythm stops scaling under WCAG 1.4.4. Contract tokens deliberately stay px — --header-h and --palette-w must keep matching MODE_CONFIGS in the main process, and a rem value would silently diverge the moment a user changed their root font size.

Type plan — system stack only; --mono is JetBrains Mono with Cascadia Mono offline. Scale 12/13/14/16/18/20/24px. Every numeric role carries font-variant-numeric: tabular-nums; src/renderer/ contains zero occurrences today, which is the single cheapest measurable win in this file. Type size is deliberately not part of the density axis: Material 3 defines density as changing "top and bottom padding" and leaves text alone, which is why [data-window-mode="compact"] remaps padding, row height and the target floor but no type token. Licence: our own tokens; no third-party asset ships.

Responsive mechanism — container-type: inline-size plus size queries, Baseline Widely available since Chrome 105 / Safari 16 / Firefox 110. A frameless window the user can resize from 280px to full width has no correct viewport breakpoint, so the card responds to its own width. The 300px dock in surface 0 is not a special case; it is the same rows in a narrow container.

The three-tier rule — :root holds seeds and derivatives; the two [data-theme] blocks hold aliases and nothing else. That ordering is load-bearing, not decorative: a :root token whose value references a theme-scoped property is invalid where it is declared and silently vanishes below it (mock 07's mesh layer, mock 11's --lyne-ink). The ramp is literal rather than generated on purpose — a generator must answer to the same contrast gate as the tokens, or it generates failures silently.

  • Move 1Adopt the tiers. tokens/colors.css becomes the 12-step ramps; semantic/theme.css keeps its single @theme inline block and becomes the alias layer. No component edit.
  • Move 2Adopt the ladder and the density axis. --surface-base / -raised / -overlay / -sunken plus --border ≠ --input; wire --s-cond / --s-norm to the [data-window-mode] block in globals.css, which is the app's real density mechanism.
  • Move 3Adopt the two contracts. font-variant-numeric: tabular-nums plus a fixed numeric gutter in tokens/typography.css; the six-state law and its shape marks in the semantic layer, every hue paired with a shape and a word.
