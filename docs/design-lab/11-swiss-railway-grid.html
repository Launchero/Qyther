11 · Railway Grid — the departure board is the interface

Provenance — the Swiss Federal Railways LYNE design system, tokens taken from github.com/sbb-design-systems/lyne-design-tokens: designTokens/color.ts (field #ffffff / #000000; red family #eb0000, red85 #ff3838, red125 #c60018, red150 #a20013; the named grey ramp midnight #151515, charcoal #212121, iron #444444, anthracite #5a5a5a, granite #686868, metal #766767, storm #a8a8a8, graphite #b7b7b7, cement #bdbdbd, platinum #cdcdcd, aluminium #d2d2d2, silver #dcdcdc, cloud #e5e5e5; secondary blue #2d327d, royalLight #06348b, royalDark #0053ef), typo.ts (size multipliers of 16px), spacing.ts (strict 4px module) and border.ts (widths 1-4px, radii 2/4/8/12/16/32). That repository declares an MIT licence in its own LICENSE file — not re-verified in this session, so treat the licence as reported, not checked. The underlying doctrine is the Vignelli Canon (vignelli.org), a copyrighted text cited here as argument, not as a value source. #0b7a3b and #b06e00 are DERIVED — SBB publishes no green and no amber.

Contrast, stated rather than assumed — #eb0000 on white measures 4.63:1 and on black 4.51:1: legal as text at the 13px floor with zero headroom, so a red label is permitted but carries no margin for a sub-pixel-antialiased 125% display. This mock therefore spends red on rules, plates and the caret and never on a 12px label, and on the dark field the red is #ff3838 — 5.11:1 on #151515, computed here. graphite #b7b7b7 is 1.78:1 on white: too dim for a numeral, so the ordinal column is granite #686868 (5.57:1) in light and stays #b7b7b7 (10.2:1) on midnight, and graphite itself is kept as a hairline/plate colour. The derived amber #b06e00 is 4.14:1 on white, which fails 4.5:1 — it is a plate with black text (5.08:1), never a label. The blues #06348b/#0053ef only reach 2.2:1/2.7:1 on the midnight card, so dark-mode icons go monochrome — which is what the railway does anyway.

Type plan — the stack SBB actually ships is SBB, Inter, "Helvetica Neue", Helvetica, Arial, sans-serif: Inter is literally the railway's first fallback, which is the honest answer for a system with no embedded webfont. The SBB house face has no licence in the token repository — UNVERIFIED and unusable, and nothing here claims Helvetica as the designed-for face. On this machine, with the lab's no-external-fonts rule, everything renders in Helvetica Neue → Arial → system sans. Scale is a multiplier of 16px: 0.75x 12 / 0.8125x 13 / 0.875x 14 / 1x 16 / 1.125x 18 / 1.25x 20 / 1.5x 24 / 2x 32 / 2.5x 40 / 3x 48 / 3.5x 56 / 4x 64. This mock uses 13/18 for rows, 12/16 mono for paths, 32 for the header, 18/30 for the answer and a 40px ordinal. --mono is this repo's own JetBrains stack — LYNE publishes no mono face, so that role is DERIVED.

Geometry — spacing.ts is a strict 4px module, so every gap above is --s1…--s12. border.ts offers widths 1-4px and radii 2/4/8/12/16/32; the hard end of that range is taken: 4px structural rules (the black band, the input boundary, the selected row), 1px cloud dividers between rows, radius 0 on the card and 2px on chips, and box-shadow: none everywhere — --elev, --elev-sm and --key are literally none. Hierarchy is carried by the band, the hairline grid, the two-column row and the one red rule, not by lightness steps.

  • Move 1 — coloursGive src/renderer/styles/tokens/colors.css the named grey ramp (midnight…cloud) and the red family (--color-red-85, -125, -150) as @theme primitives; then repoint semantic/theme.css :root to field/ink and .dark to midnight/charcoal. The surface ramp (--background < --card < --popover) collapses to one field plus rules, which is the direction's whole claim.
  • Move 2 — flat geometrysrc/renderer/styles/tokens/radius.css becomes --radius: 0 with a single 2px chip rung, and tokens/shadow.css drops every elevation token to none. Because @theme registers both namespaces, this moves the pristine components/ui/ primitives too, with no component edit.
  • Move 3 — the board markupThe 40px ordinal column and the right-aligned path column are a grid change in src/renderer/components/ResultItem.tsx plus its wrapper span becoming display: contents; --container-header-height and the black band need a top strip in CommandPalette.tsx; and the 13/18/32/40 rungs with their own leading pairs are new --text-* entries in tokens/typography.css.

Cost — about token-only, with three component marks. tokens/colors.css gains the named greys and reds, radius.css → 0/2, shadow.css → none, typography.css gains the 2x/3x/4x rungs each with their own leading pair, and motion.css is untouched because the direction ships no easing of its own here. What is not a token: the ordinal column and the right-aligned path column need markup in src/renderer/components/ResultItem.tsx, plus a band row in CommandPalette.tsx.

Biggest risk — removing the grey selection pill takes away the affordance arrow-key scanning depends on. A single 4px red rule under a row is a weaker target than a filled row: it cannot be seen in peripheral vision, it vanishes if a row scrolls to the clip edge, and every state useKeyboard can reach (selected, hover, focus) now competes on one hairline-dense row. Second-order: a 64px display rung cannot fit the 72px compact bar, so the 4x rung in the type law is unusable in the palette's own default mode.
