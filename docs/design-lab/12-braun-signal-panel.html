12 · Rams Panel — a moulded field with one honest signal dot

Provenance — the doctrine is Dieter Rams' ten principles for good design as published by Vitsoe (vitsoe.com/dieter-rams/ten-principles-for-good-design), read as rules about surfaces and material rather than as a mood. The objects: Braun ET66 calculator (1976), Braun RT20/SK4 radio (1961), Vitsoe 606 shelving (1959). No manufacturer publishes hex values for this hardware, so the palette is DERIVED from the period objects, not lifted from a spec: field #3a3a3c graphite / #efece6 paper, key face #242426, moulded-joint rule #5b5b5d, one signal #4bd06b and one fault #f2573c, function-key accents DERIVED #c8b73c and #2f6fb6. Typeface: Overpass, SIL Open Font License 1.1, verified at google/fonts/main/ofl/overpass/OFL.txt. DIN 1451 as standard lettering is out of copyright, but FF DIN and DIN Next are commercial and D-DIN's terms were not verifiable this session — marked UNVERIFIED and not used.

The number that decides the design — #4bd06b measured on the graphite field #3a3a3c is 5.69:1, and on the black key face #242426 7.77:1: safe as a label glyph, not something to set 13px prose in. On the light paper field it is 1.69:1, so the light theme ships a darkened DERIVED green #1d7a3a (4.57:1 on paper) for signal text and keeps #4bd06b as the dot. The dot is therefore never smaller than 12px and colour is always paired with a shape: filled disc = on, ringed hollow = off. Colour-only status fails WCAG 1.4.1 regardless of contrast ratio, and an agent UI that reports tool success, error and pending has no licence to fail it. That — not the aesthetics — is what this direction brings to Qyther.

The rest of the measured table — --foreground 15.62:1 (light) / 10.05:1 (dark) on the field, --muted-foreground 5.66 / 4.67, the 12px ghost placeholder --input 5.75 / 4.67, the selected-row inversion 16.76 / 16.31, the black key face carrying paper ink 14.10 / 13.72, the two function-key caps 9.03 (yellow, black print) and 6.23 / 4.57 (blue, paper print). The fault disc #f2573c is 4.58:1 only on the black key plate used for the not-ready card; on graphite it is 3.35:1, so on the field it stays a fill and the tool trace uses the derived --fault-ink (#b23a20 5.06, #ff8a72 4.93). The focus perimeter is 4.38 / 4.98 — clear of 1.4.11, not of 4.5, so it is never a label. And two steps readers will not see as elevation: --popover against the card is 1.07:1 light / 1.19:1 dark, and --border against the card is 1.75 / 1.67 — a raised surface here is a moulded joint plus an inset lip, not a shadow.

Type plan — Overpass is the shippable DIN 1451 substitute; it must be vendored, because a sandboxed renderer has no CDN and OFL is the only licence class that permits embedding. Without it the stack falls to DIN Alternate (macOS) → Bahnschrift SemiCondensed (Windows 10+, DIN-1451-derived, referenced by family name only) → Roboto Condensed → Arial, so the panel keeps a condensed grotesque character but loses its exactness. Paths and key caps: Overpass Mono, then JetBrains Mono (OFL 1.1), then Cascadia Mono. Scale: rows 13/17, caps labels 12/13 at letter-spacing: .12em, panel titles 16/22, answer body 17/28, and no display size at all. DIN's large x-height is what lets 13/17 hold; the app's 12px floor is kept, which is why every 11px caps label in this direction was lifted to 12 — the one place it is less strict than Rams' own drawings.

Geometry — a 4px grid with the step exposed as a token so every gap is a multiple of it; radius 0 for panels and cards, 2px only for recessed key faces and caps; every boundary is 1px solid var(--border) plus the moulded-plastic edge inset 0 1px 0 rgba(255,255,255,.06), inset 0 -1px 0 rgba(0,0,0,.35). There is no blurred shadow anywhere in this file — --elev and --elev-sm are declared none and depth is carried by the surface ramp, the 1px joint and the inset edge. Every rule stops 12px short of the card edge so it reads as a moulded seam rather than a hairline, and a 1px repeating-linear-gradient louvre band sits under the input at a 5px pitch. Selection is a contrast inversion (a pressed key), not a hue. Nothing in this file animates — the louvre, the joints, the discs and the segmented step bar are all static — so there is no prefers-reduced-motion block to write here; the one loop the app keeps (.spin) stays on its own loop token.

  • Move 1 — tokensRewrite tokens/colors.css with the graphite/paper ramp, the two DERIVED function-key hues and the #4bd06b/#f2573c pair, then both halves of semantic/theme.css (:root and .dark). radius.css: base --radius 8px → 0, which moves every corner including the pristine ui/ primitives, with --radius-xs 2px kept for keys. shadow.css: every blurred rung → none. typography.css: --font-sans → Overpass, the display rungs deleted. spacing.css: expose the 4px step and the 12px joint inset.
  • Move 2 — one new semantic pair--signal/--signal-ink plus --fault/--fault-ink, each with a .dark half that lifts only lightness (the existing --file-* convention), registered in the single @theme inline block; one inset rung --shadow-inset-moulded in tokens/shadow.css. Status text lands at 5.69:1 (dark) and 4.57:1 (light); --info/--ring as a 2px control perimeter is 4.38:1 light, 4.98:1 dark, which clears 1.4.11 but not 4.5 — so it stays a perimeter and never a label. #4bd06b and #f2573c as fills carry no text obligation.
  • Move 3 — markup, wrapped not patchedThe inset tab treatment goes into a src/renderer/components/common/InsetTabs.tsx wrapper around the pristine components/ui/tabs.tsx — ui/ is never edited, because shadcn diff has to stay cheap. The louvre band, the stopped-short joints and the filled/ringed status discs are class rules in styles/ask-mode-perplexity.css and globals.css, the two files that already own component vocabulary; no new stylesheet. ModeTabs.tsx and BrowserProgressPanel.tsx gain the disc markup.

Cost — token-only plus one new --signal-*/--fault-* semantic pair with its .dark half in semantic/theme.css, one inset rung in tokens/shadow.css, and the inset tab treatment wrapped in src/renderer/components/common/ rather than patching the pristine components/ui/tabs.tsx. One vendored font. No IPC change, no main-process change, no new dependency.

Biggest risk — grey-on-grey collapse. --border is 1.67:1 on the dark field by design (a decorative moulded joint, the same --border ≠ --input split this repo already encodes), so any component that reaches for it as a text colour instead of --muted-foreground silently drops under AA, and #4bd06b on paper is 1.69:1. Second risk, and the one that decides whether to adopt at all: "quiet" reads as the same shadcn restraint the owner already rejected — this panel only separates from the baseline if the dot, the insets and the tracked caps are all committed at once. Two of the three is a slightly flatter default theme.
