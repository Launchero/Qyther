01 · Cold Chrome — Vercel Geist

Provenance / Licence — Geist Sans and Geist Mono are SIL OFL 1.1, shipped as the npm package geist 1.7.2: ~29 KB for the Latin variable font, vendorable, no CDN. The stack declared here is "Geist Sans", system-ui, "Segoe UI Variable Text", "Segoe UI", sans-serif; a machine without Geist installed renders the system fallback, so a screenshot of this file shows the fallback until the font is vendored. Every colour below is a verified Geist step: greyscale is a pure-lightness ramp at chroma 0 (light 95%→9%, #f2f2f2…#171717; dark 10%→93%), the alpha twins #0000000d…#000000e8 do the real work, surfaces sit at #ffffff/#fafafa in light and #0a0a0a with a #000000 200 plate in dark, and the blue is authored per theme — #0070f7 (700) as fill, #0064e2 (900) for links at body size because 700-on-white measures 4.51:1. One deliberate departure, stated here: #28a948 as text on white is 3.06:1, so green is a fill/dot colour only and --success is a darkened #15803d for text (same treatment for amber, which keeps #ffb200 as a fill and #9a6700 as text).

Type plan — Geist Sans 400/500/600 (no 700 anywhere in their UI) plus Geist Mono for paths, sizes and key caps. Scale 12/13/14/16/20/32 px, leading 1.35–1.5 — so this mock runs 12/14/16/20/32 (13 px reserved for dense table text). Geist does not track out uppercase labels: labels are 12 px/500 with letter-spacing: 0, a deliberate departure from the baseline's .06em; the words are unchanged.

Geometry — 4 px grid (8/12/16/24/32/40/64/96), radius base 6 px (--geist-radius) with cards at 12 px, 800 px palette, 72 px header, 40 px row, 32 px control targets. Elevation is a ring, not a drop shadow: every floating surface is 0 0 0 1px #00000014 (dark #ffffff25) composed with one soft shadow; focus is a double ring — 0 0 0 2px <background>, 0 0 0 4px #0070f7. Motion is 150–200 ms on cubic-bezier(0.2,0,0,1) and the signature is restraint: nothing animates except a 1 px focus ring and a hover background step.

  • Move 1 · Neutral ramp — rewrite src/renderer/styles/tokens/colors.css as a hue-free greyscale (solid steps 95%→9% in light, 10%→93% in dark) and promote the alpha twins to first-class tokens; then re-point every role in semantic/theme.css at them. The accents move in one pass — --primary/--ring to #0070f7 light / #50a8ff dark, plus the per-theme tint pairs #f0f7ff/#06193a and #fff6e1/#291800.
  • Move 2 · Ring elevation — tokens/shadow.css: replace the OKLCH-tinted drop-stack with the composed border-ring (0 0 0 1px #00000014, dark #ffffff25) for cards and dialogs, and give every focusable the double ring 0 0 0 2px <background>, 0 0 0 4px #0070f7. tokens/radius.css base 8 px → 6 px with cards at 12 px.
  • Move 3 · Type — vendor geist 1.7.2 (SIL OFL 1.1, ~29 KB Latin variable font, no CDN), then swap tokens/typography.css --font-sans → "Geist Sans", system-ui, … and --font-mono → Geist Mono; cap weights at 400/500/600 and zero the label tracking.

Cost: token-only — three token files plus the vendored font; zero component edits, because Tailwind regenerates every utility from the same names.

Biggest risk: a hue-free neutral ramp makes status colour the only signal, and #0a0a0a is dark enough that the app's existing lightness-step elevation model collapses unless the surface ramp is re-spread.
