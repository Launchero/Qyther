25 · Retro-OS Bevel — Windows 95 chrome, honestly licensed

Provenance — specified from the shipped 98.css 0.1.21 dist/98.css (MIT, "Copyright 2020 Jordan Scales"), read rather than recalled. The finding that decides the adoption cost: 98.css ships zero CSS custom properties — every value in it is a literal, so there is nothing to import and the token layer above had to be written by hand out of its palette: silver #c0c0c0, #dfdfdf, #0a0a0a, gray, navy #000080, text #222, links #0000ff, fields #fff. The licence trap sits next door: the font is not covered by the code's licence. The bundled "Pixelated MS Sans Serif" is a FontStruction by "lou" under CC-BY-SA 3.0, so shipping that woff2 carries attribution and share-alike obligations on that asset alone. Same family, all MIT code: 7.css 0.21.1 (Windows 7), xp.css 0.2.6, nes.css 2.3.0.

Type plan — Segoe UI at 11-12 px (12 px here, this repo's own floor), Tahoma second: both already on Windows 10/11, nothing to vendor, nothing to licence. Mono drops to Cascadia Mono / Consolas. The admission that goes with it: without the bitmap face the style reads as a grey form, not as the period. Type is the look, and type is the one thing the licence will not hand over.

Geometry — radius 0 at every rung, window padding 3 px, title bar linear-gradient(90deg, navy, #1084d0), scrollbar 16 × 17 px, focus outline: 1px dotted #000 with no rings anywhere. Bevel recipes verbatim: raised inset -1px -1px #0a0a0a, inset 1px 1px #fff, inset -2px -2px gray, inset 2px 2px #dfdfdf; sunken (input, tree view, pre) inset -1px -1px #fff, inset 1px 1px gray, inset -2px -2px #dfdfdf, inset 2px 2px #0a0a0a; the active state inverts the four pairs; the default button adds a fifth ring — which is why the send control here is silver with an extra black ring and not the accent. Period density is recorded as --p-btn-h: 23px / --p-btn-w: 75px / --p-field-h: 21px and then refused: 21-23 px is under WCAG 2.5.8's 24 px AA target minimum and under this app's own --target-min: 32px, so every control keeps 32 px while wearing the bevel — the one place this lab deliberately departs from its source. Two further hand-corrections: gray #808080 as secondary text on silver measures about 2.2:1, so --muted-foreground is darkened to #4d4d4d, and the dark half is an invented edition (field #1a1a1e, bevels #000 / #3a3a40 / #5a5a62, a desaturated navy gradient) because Win95 shipped no dark mode — nothing in the right-hand column is sourced.

  • Move 1src/renderer/styles/tokens/shadow.css gains four named recipes — --bevel-raised, --bevel-sunken, --bevel-raised-sm, --bevel-default-ring — because a bevel is a shadow, not a border; --elev and --elev-sm then simply point at them and no component learns a new property.
  • Move 2src/renderer/styles/tokens/radius.css goes to 0 at every rung and semantic/theme.css takes the silver palette. Note the coupling: every pristine components/ui/ primitive arrives carrying rounded-* and shadow-sm, so the look is flipped through the token layer — those utilities compile onto the --radius and --shadow tokens, and editing the primitives would break the shadcn update path ui/AGENTS.md protects.
  • Move 3Three new roles and one new mechanism: --field (a sunken text field is not --background), the four --bev-* steps and a --titlebar gradient; plus ::-webkit-scrollbar at 16 px — real in Electron, absent in Firefox — and outline: 1px dotted focus, which leaves --ring declared and used by nothing.

Cost: tokens plus four named shadow recipes plus three new roles; no markup, no build step, no runtime. What it actually buys is the cheapest legible status model in the lab — a pressed control is a bevel that inverted, not a colour. The real cost is the one it cannot pay: the licensed look needs a licensed face.

Biggest risk: it reads as pastiche unless the density is honoured — and the period's density (21-23 px controls, 16 px scrollbars, 11 px type) is a target-size regression this app must not ship. Keep 32 px controls and it is a bevel-skinned modern UI, not Windows 95; ship the real sizes and it fails WCAG 2.5.8. That contradiction is the finding, not a detail to smooth over.
