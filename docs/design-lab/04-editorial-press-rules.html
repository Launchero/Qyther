04 · Press Rules — an editorial system for an agent

Provenance — an editorial direction distilled from published work (The Pudding's essay typography, Bloomberg Graphics' broadsheet grids, the letterpress-derived variable-serif revival), not a token package. Nothing here is vendored; the values in the token block at the top of this file are hand-set against our own role names so it still diffs against src/renderer/styles/semantic/theme.css. Light is the paper system: paper and raised sheet neutrals, ink at 15.88:1 on paper, one secondary grey at 4.91:1 — there is no room for a fifth grey — a cream feature plate that keeps ink at 14.19:1, spot red for status at 6.09:1, and an accent teal. Dark is a night-printing variant, not an inversion: the same ink-on-paper relation rebuilt on a dark sheet, the rule re-spelled in light ink at 14%, and the two hues only lifting lightness — the red goes to a hotter print spot, the teal to its pale twin.

Type plan — display serif Fraunces (SIL OFL 1.1, variable opsz/SOFT/WONK axes — the optical-size axis is what makes it read as letterpress rather than Times; set at "opsz" 40 for the headline, "opsz" 17 for the answer), with Instrument Serif (SIL OFL, single 400 + italic, so no weight play) as the cheaper alternative. Body and all UI chrome stay in a grotesque (Geist Sans, SIL OFL, or system); paths, kind labels and small labels stay in mono at 12px with letter-spacing:.14em and never bold. Long-form body could move to Newsreader or Source Serif 4 (both OFL). Scale 12/14/17/21/40/64, body leading 1.6, measure 68ch, headings 1.02 with -0.015em. This mock declares stacks with fallbacks only — a machine without the serif renders Georgia/Times until it is vendored.

Geometry — structure is the point: rules instead of cards. Section separators are border-top: 1px solid var(--rule) with generous air beneath; radius goes to zero (the 2px chip survives); shadows go to zero, so focus is a teal outline and elevation is a heavier rule. The palette card keeps its outline but reads as a broadsheet column, not a floating chip. 8px base with a typographic rhythm of 24/32/56/88, not a grid box. Motion is slow — 320ms cubic-bezier(0.16,1,0.3,1); the signature is the answer text settling per block as markdown commits (a 4px rise + opacity on the settled half only), and the streaming caret is a thin spot-red rule rather than a block.

  • Move 1 — tokens/radius.css src/renderer/styles/tokens/radius.css → the whole scale to zero except --radius-chip: 2px. Tailwind maps --radius-* onto every rounded-* utility, so this one file flattens every corner, including the pristine components/ui/ primitives, with no component edit.
  • Move 2 — tokens/shadow.css src/renderer/styles/tokens/shadow.css → every shadow to none; the focus rings move from shadow-inset to outline. Separation then rests entirely on rules and lightness, so --border/--input values above must be re-checked against the contrast gate before this lands.
  • Move 3 — tokens/typography.css src/renderer/styles/tokens/typography.css → the Fraunces/grotesque pairing, the 12/14/17/21/40/64 scale and the 68ch measure. Markup must change in three components that today assume a card-and-sans world: src/renderer/components/ResultsList.tsx (cards become ruled ledger rows), components/ask-mode/GenerativeUI/DataTable.tsx (the table frame becomes broadsheet rules), and components/ask-mode/ChatMessageBubble.tsx (the answer becomes the serif column; the caret becomes the spot-red rule).

Cost: this is the genuine restructure of the lab — every card surface must become a ruled block, not a recolour.

Biggest risk: 13px UI rows set in a serif are the failure mode, and generous leading makes the palette feel ~30% taller — either the file list drops to 28px rows or main's expanded-height ceiling has to change, and main owns that geometry, not CSS.
