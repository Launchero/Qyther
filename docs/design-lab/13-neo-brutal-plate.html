13 · Neo-Brutal Plate — every surface is one thick-framed plate with a hard offset shadow, radius 0, and no blur anywhere

Provenance — the recipe is quoted verbatim from neubrutalism.com: border: 3px solid #000; box-shadow: 5px 5px 0 0 #000; border-radius: 0, typeset Syne + Inter. neobrutalism.dev carries its radius, shadow and weight choices in its own globals.css and loads its fonts from Google — an offline sandboxed renderer (this app: sandbox: true, no CDN in the CSP) cannot do either, so nothing here depends on a network fetch. Both sites state plainly that loud palettes do not guarantee compliance. Compliance truth, computed: acid yellow #ffd80f against black is ≈13:1 (a great plate with black text on it); pink #ff7ad9 with black text is ≈7:1; pink with white text is 1.4:1 — so this mock never sets white text on an acid fill, and neither may an adoption. The #00a43c and #d40000 status values each clear 4.5:1 in only one theme (green 5.8:1 on near-black but 3.2:1 on cream; red the reverse), so each theme carries one published value and one DERIVED darker/lighter partner. The dark half is our invention: #000 frames vanish on a dark field and every published recipe in this trend is light-only; this direction was never designed for dark mode, and the fix authored here is #f5f5f5 frames and offset plates on a near-black field, keeping the acid fills unchanged with black text always on top.

Type plan — Inter 400–900 (OFL) for UI; rows at 13/17 go to weight 500 with letter-spacing: .01em, because 13px Inter at 400 inside a 3px black frame reads grey. Display 32–64px uses Anton (OFL 1.1, verified) — the banner falls back to Archivo Black, then Arial Black/Impact. Syne, the face the published recipe pairs with Inter, is marked UNVERIFIED: its licence could not be confirmed this session, so it is substituted outright. On a machine with none of these, UI falls to Segoe UI and display falls to Impact — the banner still reads brutal because the geometry, not the face, carries the direction.

Geometry — strict 4px grid; radius 0 everywhere; cards border: 2px solid #000; box-shadow: 4px 4px 0 0 #000; rows, chips and mini-plates 2px 2px 0 0 #000; no blur token exists in this direction at all. Focus is outline: 3px solid #000; outline-offset: 2px — outline, not box-shadow, because Radix popovers clip shadows. Signature devices, both themes: the card as one thick-framed plate; the selected row as a solid acid-yellow plate that shifts translate(-1px,-1px) and grows its offset on hover/selection; key labels as black-on-yellow 2px-framed chips; a rotated −3deg black band behind the mode tab label; the tool-activity log as stacked mini-plates in a strict 4px rhythm.

  • Move 1Radius and shadow via existing rungs: tokens/radius.css to --radius: 0px (Tailwind maps the whole --radius-* namespace onto every pristine components/ui/ corner), tokens/shadow.css re-author every --shadow-* as Npx Npx 0 0, semantic/theme.css both halves to the hex palette.
  • Move 2Border width has no rung today — add --border-width-plate: 2px as a new rung (a tokens/border.css with the usual @import into styles/globals.css before the semantic layer), then flip or wrap: every components/ui/ primitive shipping border-input + shadow-sm renders a 1px Tailwind border, so it needs either an upstream diff or a components/common/ wrapper that re-declares border-2.
  • Move 3Geometry compensation, in two owners: tokens/spacing.css raises --target-row 40→44px (the frame is inside the row); --container-header-height must keep equaling main's MODE_CONFIGS.compact.height in src/main/windowManager.ts, so the 72px compact bar is a main-process change, not a CSS one.

Cost: tokens cover radius, shadow and border colour, but there is no border-width token in src/renderer/styles/tokens/ today, so a --border-width-plate: 2px rung must be added, and every components/ui/ primitive shipping border-input + shadow-sm needs a token flip or a wrapper in components/common/.

Biggest risk: 2–3px borders across ~30 rows add 4–6px each, so --target-row: 40px effectively becomes 44px and the 72px compact bar is consumed by its own frame; and hard offset shadows get sliced by CommandPalette's overflow: hidden — the plate can only cast a shadow outside the card if the card stops clipping it, which touches the drag-handle and Radix-portal layering decisions recorded in src/renderer/AGENTS.md.
