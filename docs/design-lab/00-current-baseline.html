00 · Current baseline — shadcn/ui + Radix on Tailwind v4 OKLCH tokens

Provenance — vendored shadcn/ui primitives in src/renderer/components/ui/ on Radix, themed in three layers: styles/tokens/*.css → styles/semantic/theme.css → component. Every value above is read from semantic/theme.css verbatim, both halves. Licence MIT.

Type plan — system stack only (Segoe UI Variable Text on Windows); --mono is JetBrains Mono, referenced from a CDN and falling back to Cascadia Mono offline. Scale 12/14/16/18/20/24 px, each rung carrying its own line-height and letter-spacing.

Geometry — strict 4pt grid, 8 px base radius, 800 px palette width, 72 px header, 40 px row. Elevation is a lightness step + border + tinted shadow together; --border (decorative) is deliberately a different value from --input (control boundary, 3:1 per WCAG 1.4.11).

  • Move 1Colour only: rewrite tokens/colors.css ramps and the :root / .dark blocks in semantic/theme.css. No component edits.
  • Move 2Corner and depth language: tokens/radius.css moves every corner including the pristine ui/ primitives; tokens/shadow.css moves every floating surface.
  • Move 3Rhythm: tokens/spacing.css owns --target-row, --header-height and the padding vocabulary; tokens/typography.css owns both stacks and the six-rung scale.
