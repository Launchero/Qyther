28 · Derived Token Algorithm — Ant v5 tiers, Radix 12-step, Primer state matrix

Provenance — three published packages, MIT. antd@5.29.3 (latest-5) documents the algorithm verbatim: Seed (designer) › Derivative (designer) › Alias (developer), plus 30+ alias roles shadcn never names (colorFillContent, colorSplit, colorTextPlaceholder, controlItemBgHover, controlOutline, lineWidthFocus, boxShadow). Seeds read from the shipped theme: colorPrimary #1677ff, colorSuccess #52c41a, colorWarning #faad14, colorError #ff4d4f, fontSize 14, borderRadius 6, controlHeight 32. @radix-ui/colors@3.0.0 supplies the 12-step discipline: 33 scales, steps 9/10/11/12 reserved for border / hover-border / muted-text / text, quoted gray-cool #fcfcfc #f9f9f9 #f0f0f0 #e8e8e8 #d9d9d9 #d6d6d6 #cecece #bbbbbb #8d8d8d #838383 #646464 #202020. @primer/css@22.3.2 / @primer/primitives@11.10.0 supply the state vocabulary and the theme matrix: role→property names (--fgColor-danger #d1242f, --borderColor-emphasis #818b98), geometry tokens (--borderWidth-thin .0625rem), and 14 shipped functional theme files, not 9. Everything on screen is DERIVED from three seeds; accessible text is a derived step, never a raw seed.

Type plan — a system stack, not a webfont: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, 'Noto Sans', sans-serif, mono 'SFMono-Regular', Consolas, 'Liberation Mono', Menlo. Ant ships this stack; Qyther already declares the same decision in tokens/typography.css. Nothing to vendor, no licence exposure — the reason this direction is cheap.

Geometry — Ant seeds fontSize 14 / borderRadius 6 / lineWidth 1 / lineWidthFocus 2 / controlHeight 32, snapped to Qyther's existing 4pt grid and 800×72×40×32 dimensions. Borders are 1px; the focus ring is a 2px perimeter. Elevation is Ant's two-level tinted shadow set (--elev / --elev-sm), not a lightness step.

  • Move 1Restructure tokens/colors.css into seed + derivative tiers: one seed set and the generated ramps, replacing the hand-tuned mist/gray ramps. The 12-step reservations land as --n9…--n12.
  • Move 2Add component-state aliases to semantic/theme.css — --control-bg-rest, --control-hover-bg, --control-active-bg, --control-outline, --line-width-focus, --split, --fill-content — alongside the existing role names, in both :root and .dark.
  • Move 3Wire --line-width-focus: 2px as the focus ring width in tokens/shadow.css / motion.css and gate the generator with node tmp/contrast-full.mjs --strict, so a derived pair that misses the floor fails the build rather than shipping.

Cost: the cheapest architectural change in the whole lab — no new fonts, no markup, no blend modes, no wrapper elements. It is a restructure of two stylesheet tiers and a set of new aliases; components keep reading var(--primary) etc.

Biggest risk: an algorithm that generates values can generate values that fail a contrast floor silently, so the generator must be gated by the same --strict check the hand-written tokens are. Ant's own runtime CSS-in-JS (@ant-design/cssinjs) injects <style> at runtime, which collides with the CSP meta in src/renderer/index.html — take the token model, never the renderer.
