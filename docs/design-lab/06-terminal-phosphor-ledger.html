06 · Phosphor Ledger — a terminal-native agent surface

Provenance — Solarized, by Ethan Schoonover: a palette and a spec (a base ramp of eight greys plus eight accents, each with a stated role and a measured ratio), not a redistributable token package — nothing to vendor, values retyped here verbatim. It is the accessible distillation of the 16-colour ANSI family, and it is the only scheme in this lab built for a monospaced grid — which is what a file tool and an agent trace actually are. Licence: the palette and its specification are freely published; no font or code is redistributed.

Type plan — monospace everywhere, with no licence risk and no new dependency: JetBrains Mono is SIL OFL and is already this app's --font-mono in tokens/typography.css, with Cascadia Mono and Consolas behind it offline. This direction is a promotion of an existing stack, not an import; IBM Plex Mono and Space Mono are the OFL alternates. --ff and --mono are set to one stack. Scale 12/13/14/16/24/32 px at leading 1.5 — mono needs roughly +0.1 leading over proportional and pays for it in measure, so prose is cut to 68ch. No letter-spacing anywhere except +0.04em on the 12px uppercase column heads; font-variant-ligatures: none on every path, so es.exe never renders as one glyph.

Geometry — pad by the character: padding-inline: 1ch, padding-block: .5em, gaps in ch, the definition list's first column two em-boxes wide. Radius is zero everywhere except 2px on the caret. Borders are solid 1px; shadow is none and --key with it — depth is a one-cell inset plus a border step, and the only glow in the file is text-shadow: 0 0 6px #2aa19833 on the accent line. Motion is 90ms linear: phosphor does not ease. The signature is a solid block caret that inverts the cell rather than blinking — .caret { background: currentColor } with the glyph refilled in var(--background) via -webkit-text-fill-color, since currentColor on the same element resolves to that element's own color and a naive color: var(--background) would cancel itself into an invisible cell. That is the one rule that reads as a markup-visible change (and even that reuses the <span class="caret">▊</span> the baseline already ships). Optional scanlines sit on .desktop::after at 8% and switch off under prefers-reduced-motion. Limits, stated: no animated flicker or opacity pulse anywhere (WCAG 2.3.1); saturated green and magenta on near-black carry high luminance but their chroma makes small text shimmer, so 12–13px text stays #eee8d5 / #93a1a1 and colour is reserved for status glyphs, never prose; cyan on #002b36 is 4.75:1, so cyan-as-text is confined to 16px and above; a glow on 11–12px text destroys its own contrast, so it is applied only to the 14px selected title and the caret; and Solarized's own base01 on base02 (4.06:1) is the floor for 12px status words in the dark half — the light half's hues are darkened until every text pair clears 4.5:1.

  • Move 1Push --font-mono up the stack: tokens/typography.css promotes the mono family to --font-sans / --font-body, both stacks become one, leading goes to 1.5 and --tracking-tight goes to zero. No new dependency and no licence work — the font is already installed and vendored.
  • Move 2tokens/colors.css takes the two Solarized ramps (base03…base3 and the eight accents) as its only primitives, and semantic/theme.css re-derives every status pair from them — cyan as a fill in the dark half, base01 reverse video in the light half, and the light half's green/yellow/blue/red/violet darkened until each clears 4.5:1.
  • Move 3tokens/spacing.css moves row, cell and header padding to ch units so the grid is laid out in characters; tokens/radius.css goes to 0 except a 2px caret exception, and tokens/shadow.css goes to none — every --shadow-*-colored step is replaced by a one-cell inset.

Cost — token-only, plus one class rule for the inverted caret: typography.css, colors.css, semantic/theme.css, spacing.css, radius.css, shadow.css, no component file touched, and nothing in pristine components/ui/ that a shadcn update would fight. Biggest risk — monospace-everything gives up the proportional readability of answer prose at 16px, and the app's file paths are already mono, so the direction's differentiator disappears exactly where it is strongest today.
