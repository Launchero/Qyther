15 · Poster Scale Type — Public Theater size jumps, inside 800 px

Provenance — Paula Scher's identity for The Public Theater, read from three documented artefacts: Pentagram's own project page for the work, the Cooper Hewitt post Everyone's Public Theater (2018-04-05), and the typeroom write-up. Together they name the faces (wood type, Akzidenz-Grotesk, Knockout), the palette (blue, red, yellow on paper) and the stated intent — Scher rejected the modernist grid for flush-left ragged-right type set at whatever size the word needed. The four colours above are DERIVED from that campaign's printed range, not from a published token file: paper #f7f4ee, ink #0d0d0d, blue #123fa5, red #d8232a, yellow #f2c10a. Computed on paper: blue ≈8.4:1 and red ≈4.6:1 — both usable as 13px text — while yellow is ≈1.5:1 and is a plate only, never text; where yellow carries words it carries ink (≈11.5:1). Licence reality: Akzidenz-Grotesk (Lineto) and Knockout (BlueType) are paid, and a desktop font licence is not an app-embedding licence — the general rule is spelled out on Monotype's and Swiss Typefaces' licensing pages. The shippable substitutes below are all verified SIL OFL 1.1 in the google/fonts repo: Anton (google/fonts/main/ofl/anton/OFL.txt, a single-weight condensed grotesque — the closest legal spirit of Knockout), Big Shoulders Display (variable 100–900, more weight control if a second rung is ever needed) and Archivo Black; Inter (OFL) carries the 13px UI.

The idea — what makes this authored is the size jump, not the size. The scale here is 12/16 for meta, 13/17 for rows, then a jump — about 3.7x body — to 48/48 for the typed-query echo, and about 5x to 64/64 for the Ask headline. Everything is mixed case, flush left, ragged right, and the credit line — 12px caps, +0.08em — sits underneath the huge word it describes. That inversion (tiny authority under enormous type) is the Scher signature and it is the whole reason this file exists; a direction that merely made the display face big would be a font swap.

Type plan — --disp is Anton, "Big Shoulders Display", "Archivo Black", Impact, Haettenschweiler, "Franklin Gothic Bold", "Arial Narrow". No webfont is loaded in this mock, so on a Windows machine with none vendored the 48/64px rungs render in Impact — a condensed poster face that sits in the same register and is the reason the fallback chain is honest rather than decorative. Body and UI are Inter with a system-ui / Segoe UI fallback; paths, kbd caps and numbers are JetBrains Mono with a Cascadia/Consolas fallback.

Geometry — 4px grid, radius 0 everywhere, and border-bottom: 4px solid var(--rule) as the only divider (head, echo block, selected row, table head, footer). No elevation: --elev, --elev-sm and --key are all none, and every control that would have cast a shadow is instead drawn with a 2px solid ink border. Focus is a 3px inset plate ring (--ring red on paper, yellow on ink). The footer carries a 1px repeating-linear-gradient newsprint rule — the only texture in the system. The 72px header is not part of the poster: all display type lives in the results area.

  • Move 1Type scale, token-only: src/renderer/styles/tokens/typography.css gains the two poster rungs with their own leading and tracking pairs (--text-echo: 48px/48px, --text-poster: 64px/64px, --text-plate: 40px, plus --text-meta 12/16 and --text-row 13/17) and the --font-display stack. Tailwind emits text-echo/text-poster utilities automatically, so the 3x/4x jumps land with zero component edits.
  • Move 2Colour and geometry: tokens/colors.css gains the four campaign hues as primitives (paper / ink / blue / red / yellow); semantic/theme.css maps them into the existing roles with a .dark half for each, where --primary-foreground flips to ink because the lifted dark blue carries paper text at only ≈2.5:1. tokens/radius.css goes to 0 on every rung — which moves the pristine ui/ primitives too — and tokens/shadow.css goes to none.
  • Move 3The two devices that need markup: a display echo block in the results area (ResultsList / CommandPaletteBody) and the flush-right caps credit line (CommandPaletteHeader.tsx and ChatMessageBubble for the 64px first word of an answer). Rows, tiles and dialogs restyle from tokens alone.

Cost — tokens/typography.css gains the 3x/4x rungs with their own leading and letter-spacing pairs and colors.css/semantic/theme.css gain the hues: token-only, no component touched. But the header device needs new JSX in src/renderer/components/CommandPaletteHeader.tsx. And the expensive consequence: if a display echo ever makes the compact bar taller than 72px, --container-header-height — which is contractually equal to main's MODE_CONFIGS.compact.height — has to change, and that drags in src/main/windowManager.ts, the harness MODE_HEIGHTS in scripts/harness/driver.mjs, and src/main/windowManager.test.ts. So the giant type stays inside the results area, under the 4px rule, and the header stays exactly one ink rule thick. That constraint is the reason this direction is drawable at all.

Biggest risk — a 64px Anton line in an 800px frame fits roughly 11 characters, so the device must clamp (this mock uses white-space: nowrap; overflow: hidden; text-overflow: ellipsis) and long queries will hit it. Dense file lists and poster type genuinely disagree: the rows stay 13px or this stops being a launcher. And Anton ships one weight, so hierarchy has to come from size alone — no bold/medium axis, no letter-spacing trick at small sizes; the 11-12px caps credit line has to be Inter, not Anton, because single-weight condensed type at caps is barely legible.
