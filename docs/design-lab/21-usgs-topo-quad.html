21 · Quadrangle — the USGS topographic sheet, where colour is a claim about the class of information

Provenance — the direction is USGS cartography, and it is in this lab for one reason: it is the only system here whose colour logic the app already has. USGS's published rule, in the Survey's Topographic Map Symbols General Information Product (pubs.usgs.gov/gip/TopographicMapSymbols) and in the US Topo cartographic specifications (2023), is that colour encodes the class of information, not mood: “topographic contours in brown; lakes, streams, irrigation ditches and other hydrographic features in blue; roads in black and red.” The same guide states verbatim that “topographic contours are shown in brown by lines of different widths” and that “the contour interval is printed in the margin of each U.S. Geological Survey (USGS) map” — that last sentence is where this mock's marginalia block comes from. Qyther already ships --file-typescript/javascript/python/rust/go as a file-class legend, so the identity is load-bearing rather than cosmetic — and the sheet's marginalia (scale, declination, contour interval) is a native metaphor for the chrome a palette has to show: mode, window height, token cost. USGS publishes classes, not hexes, so every numeric ink below is DERIVED by this lab: umber/contour #9A6B4F, hydro blue #2C6F9B, survey red #C2472B, cultural black #1B1A17, quad paper #EFE8D8, buffer-tan band #E3D4B0; the sheet tint, hover screen and collar stock are DERIVED tints of the paper, and --agent rides on the published purple class — the one USGS reserved for urban-renewal and proposed-feature amendments (the guide notes purple is no longer added in current revisions but is still on many sheets), which is precisely what a pending tool step is: marked on the plan, not yet on the ground. The dark half is the night-surveil edition: a black field with umber and hydro as glows. Say it plainly — tan is a light-only field, so the dark column is an authored second edition, not an inversion of the first. Adopting it means re-expressing every value in OKLCH, which src/renderer/styles/tokens/colors.css mandates; licences: Oswald and Archivo are SIL OFL 1.1 (both verified), JetBrains Mono is OFL 1.1 and already this app's --font-mono; the USGS symbols manual is a US-Government work, no licence encumbers the rule.

Type plan — map place-names are small, condensed, mixed-case and generously tracked: --name is Oswald, falling to Archivo (both OFL 1.1), then Arial Narrow/Haettenschweiler on any Windows box that has neither, then the system sans — the look survives the fallback because it is carried by the condensed ratio and the +0.045em tracking, not by a single face. Graticule, easting and station notes are JetBrains Mono. Rows 13 px, row titles 14 px, marginal notes 12 px; the real map habit of 11 px place-names sits below this app's 12 px floor (tokens/typography.css: “never add a size below 12px”), so it is not taken — the control's three 11 px literals are lifted to 12 px here. Selection, focus and the send control are drawn in cultural black, never in a class ink.

Geometry — a neatline: a heavy outer frame with a hairline inner line inset 5 px and L-shaped corner ticks built from gradient bars, on a card of radius 0; the 4 px key-cap radius survives because key caps are the one legitimately rounded thing on the sheet. A 24 px graticule pitch with a heavier line every 96 px, drawn as two crossed repeating-linear-gradient pairs and confined to the header band, the hero and the empty state — never behind rows. No shadow anywhere (--elev/--elev-sm/--key = none): on a map nothing floats, so surfaces are separated by rules and screens, and each row carries a 3 px left station bar in its class ink. Border widths are tokens (--bw 1 / --bw-2 2 / --bw-3 3). Nothing in this mock animates — a survey sheet is not in a hurry — so no reduced-motion block is needed and none is present.

  • Move 1 — the rule, enforcedRe-tint the five --file-* pairs in src/renderer/styles/tokens/colors.css + semantic/theme.css into four USGS classes — contour brown = code and stylesheets, hydro blue = prose, cultural black = structure/boundary, survey red = the governing document (AGENTS.md, specs) — each with a .dark half and -text siblings, then give ResultItem/FileTypeIcons a one-line class→ink map and a --file-class custom property so the row's station bar, icon and kind label are all written by that one property in one place. The five language inks collapse to four class inks: language stays in the kind label, not in the colour.
  • Move 2 — the sheet, in four tokensAdd --paper, --buffer, --graticule and --graticule-major to tokens/colors.css and register both halves in semantic/theme.css; set radius to 0 in tokens/radius.css (keeping --radius-shortcut-key: 4px) and shadows to none in tokens/shadow.css. --graticule-bg, --ticks and --scale-bg must be declared inside the :root/.dark blocks, not on :root, or the substitution is invalid where it is declared and the device silently vanishes.
  • Move 3 — marginalia as chromeName faces and tracking in tokens/typography.css (Oswald/Archivo stack, --tracking-place: .045em); vendor only the Oswald latin subset, ~60 KB — no multi-megabyte variable face, no blend mode. Markup: the neatline and corner ticks are two pseudo-elements on the CommandPalette card, the declination needle is a clip-path <i> in ModeTabs and ThemeToggle, the legend box and scale bar are the collar note for SearchEmptyState and SettingsDialog, and the TaskMetrics block gains a stated contour interval so the units are printed, not implied.

Cost: MEDIUM. Re-tint the five existing --file-* pairs into the four USGS classes with both halves and re-run the contrast gate (node tmp/contrast-full.mjs --strict); add --paper, --buffer, --graticule, --graticule-major to tokens/colors.css and semantic/theme.css; radius to 0 in tokens/radius.css; shadows to none in tokens/shadow.css; ~8 lines of component markup for the neatline, needle, legend and scale bar. The honest selling point: no blend modes, no portal risk, no multi-megabyte font — the cheapest genuinely impressive option in the lab, and the only one that gets stronger the more of the sheet you draw.

Biggest risk: a graticule sitting directly under 13 px text measurably costs contrast, so it must never be behind rows — the header band, the hero and the not-ready empty state are its only homes here, and its alpha is capped by measurement, not by taste: at 35% umber on quad paper the worst text-over-line crossing is 4.78:1 (light) and at 20% it is 4.90:1 (night edition), so the night edition runs the lines fainter still — a glow sheet cannot spend contrast on grid ink. And the whole thing turns into novelty the instant colour is decoration: it is only defensible under the enforced rule “ink = file class”, which is why selection, hover, focus and the send control are cultural black. Legibility of the published inks, measured on quad paper: hydro blue 4.46:1, survey red 4.07:1, contour umber 3.75:1 — under the 4.5:1 a 12–14 px label needs — so the class inks are rules, station bars, swatches and glyphs, and every one of them carries a darkened (light) or lifted (dark) -text sibling for words: #6B4630 7.44:1, #215A80 6.67:1, #8E3118 7.28:1 on the sheet, all ≥4.5 on the buffer band too.
