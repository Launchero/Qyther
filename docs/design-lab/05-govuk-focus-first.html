05 · Focus First — a public-service utility system

Provenance — the GOV.UK Design System, specifically the palette, spacing and focus primitives in govuk-frontend SCSS (settings/colours/palette.scss, settings/spacing/, core/links, objects/). Licence: MIT, Crown copyright. Functional mapping copied, not approximated: text = black #0b0c0c, secondary text = black tint-25 #484949, border = black tint-80 #cecece, input border = full black, focus = yellow #ffdd00 plate with black text, link = blue shade-10 #1a65a6, link hover = shade-50 #0f385c, visited = purple #54319f. Measured on white, re-derived for this file: black 19.59:1, secondary 9.03:1, link 6.08:1, link-hover 12.07:1, black-on-focus-yellow 14.55:1, input black 19.59:1. The decorative tint-80 rule is 1.57:1, not the 4.56:1 figure this direction is usually quoted with — 4.56:1 belongs to a #767676-class mid-grey, so this mock keeps tint-80 for dividers and spends all of its boundary weight on the control instead. The dark half is authored as a night-service plate (#0b0c0c background, white text, secondary #cbcbcb 10.96:1, border #565656, input border white, focus yellow unchanged, link #5694ca 5.49:1); every text pair sits at or above 4.5:1.

Type plan — their stack is "GDS Transport", arial, sans-serif, and GDS Transport is licence-restricted to *.gov.uk / service.gov.uk: it is not shippable here, and downloading it would be the one part of this adoption that cannot be done. The substitution GDS itself prescribes is Arial/Helvetica, so this mock declares Arial, "Helvetica Neue", system-ui, sans-serif. If a bundled face is wanted later, Archivo or Inter (both OFL) are the upgrade path. Weights 400 and 700 only — no 500, no 600. Their real responsive scale is 16/19/21/24/32/48/80px with 24-50px leading; this mock keeps 13/16/20/28/40 with letter-spacing flattened to 0, which is a page-scale system compressed into a palette. That compression is the honest test of the direction: 24px is their first heading rung, and a 40px row cannot hold their body size. Because the row title is the only actionable thing in the list, it wears the link: shade-10 with a 2px underline, which measures 5.48:1 on the tint-95 hover plate — still over the 4.5 floor. The match `<mark>` is a yellow plate at 14.55:1, and inside the yellow focus plate it flips to a black underline, because yellow-on-yellow is invisible.

Geometry — spacing is 5/10/15/20/25/30/40/50/60 px. It is not an 8px grid, however often that is repeated: 5 and 15 and 25 exist on their own terms, and an 8px translation loses the half-steps. Radius is ZERO everywhere — not the smallest rung, zero, including on the card, the spinner (a conic wedge instead) and the toggle (which becomes a square knob in a square track). Shadows are ZERO, so the entire elevation language is the one 5px solid black rule plus steps of value. A 5px 5px 5px 0 solid black bar marks an interactive block; the edge a palette row can actually spend is the leading one, so it is drawn as a left bar. Motion is 150ms colour-only, and the signature ordering — focus arrives before hover — is why the yellow plate is rendered permanently on one row rather than described.

  • Move 1 — collapse the token system
    src/renderer/styles/tokens/radius.css → every rung 0. Tailwind v4 maps the --radius-* namespace onto rounded-*, so one file moves every corner including the pristine components/ui/ primitives, with no component edit. tokens/shadow.css → none for all of --shadow-command-palette / -popover / -dialog / -tooltip / -toast / -shortcut-key; the five surfaces then separate only by border and value step.
  • Move 2 — re-map colour and type
    src/renderer/styles/semantic/theme.css → --input becomes the loudest line on the page (full black in light, white in dark) while --border drops to a 1.57:1 decorative hairline; --ring stops being a ring and becomes the yellow plate, so focus-visible:ring-2 ring-ring/30 in the primitives reads as a plate rather than a halo. tokens/typography.css → the Arial stack GDS prescribes and 400/700 only; --font-mono loses JetBrains and falls to Cascadia Mono / Consolas.
  • Move 3 — the two things the tokens cannot do
    The 5px left bar needs markup: src/renderer/components/ResultItem.tsx already grids its own <span> cells, so a bordered wrapper has to be added. The yellow focus plate must override the pristine src/renderer/components/ui/input.tsx focus-visible: utilities, and per src/renderer/components/ui/AGENTS.md a primitive is never edited — it lands as a [data-slot="input"] rule in src/renderer/styles/globals.css, which is also where border-radius: 0 beats the upstream utility.

Cost — colour, radius and spacing are token-only and genuinely cheap: three files, no component touched, and the --radius-* / --shadow-* collapses are a one-line-per-rung change. The 5px left bar and the yellow focus plate are markup: a wrapper in ResultItem.tsx (and wherever else a block must be marked), plus a [data-slot] override in globals.css for every primitive that currently draws its own focus ring.

Biggest risk — a yellow focus plate is loud in an always-on-top palette: the window floats over whatever the user was already looking at, so a full-width #ffdd00 bar plus a 4px black underline competes with the desktop underneath it and reads as a system alert rather than a caret position. Second, the black left bar lands in the file-type icon column — grid-cols-[var(--spacing-7)_…] is 28px wide and a 5px black rule eats 18% of it, so the extension glyph and the bar fight for the same 15px. Third, a page-scale type ramp does not survive compression to 13px rows: their link is an underlined sentence-level affordance at 19px, and six 13px underlined titles stacked in 40px rows read as a wall of hyperlinks rather than a file list — while the 400/700-only weight limit leaves nothing under bold to soften a path with.
